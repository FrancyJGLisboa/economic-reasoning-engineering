# Documented judgment transfer pilot

## Question

Does the current faithful package help a model reproduce judgments documented in other source material?
This pilot measures reference agreement, evidence navigation, and attribution limits separately.
It does not evaluate market forecast accuracy or establish an identical persona.

## Frozen design

The source package contains one fertilizer transcript and three documented method fragments.
Three judgments from three other transcripts remain outside the evaluated model's context.
A fourth case tests unsupported attribution when automatic captions do not identify a financial instrument reliably.
The fourth case is an investigator-designed control. It is not a fourth historical instrument decision.

An initial Claude run was rejected by a weekly usage limit. It produced no answers and is excluded.
A separate Codex cohort ran four fresh sessions in baseline, package, package, baseline order.
The default runtime banner resolved model gpt-6.1-sol with medium effort.
The answer events do not expose the exact backend model revision.

Both conditions used the same case facts, answer schema, instructions, and CLI settings.
The package condition received the complete portable folder rendered as text with file-path headings.
The baseline received no source-person package.
This cohort does not measure filesystem navigation or selective reading.

Shell execution, collaboration, memory, web search, apps, plugins, and hooks were disabled.
User configuration was ignored and project-document loading was disabled.
The runtime reported ignored malformed local role definitions in every session. No tool actions occurred in the evaluated turns.
Reference answers remained outside the model payload.

Cases, reference answers, source hashes, package inventory, and scoring rules were frozen before answer runs.
The fallback cohort recorded a separate presentation amendment before its first response.
The system prompt and output schema were also frozen before the first response.
No response was repaired or replaced by the investigator before scoring.

## Measures

Historical conclusion agreement counts exact choices for the three historical cases.
Criterion agreement counts the selected primary criterion against the frozen reference.
The attribution control requires refusal to identify an undocumented instrument.
Two repetitions provide six historical responses per condition. They do not provide six independent historical cases.

Evidence checks resolve cited method IDs and zero-based source-reference indexes.
Reference checks inspect method IDs, source indexes, and exact retained anchors. File-read navigation remains outside this cohort.
Correct attribution requires separating a new application from a documented judgment in the historical test case.
A valid citation does not establish that its source supports the entire new conclusion.

## Interpretation limits

The investigator previously saw the full source collection.
Isolation applies to the evaluated model. This is not an investigator-blind study.
The investigator selected the cases, alternatives, and reference labels.
No human has verified that rubric or scored the answers.

Multiple-choice alternatives and supplied case facts may make correct answers accessible without the package.
Equal scores cannot establish a package benefit. High scores cannot establish general behavioral equivalence.
The package contains one source. Its subject coverage is limited.
A single model and two repetitions cannot establish compatibility with other models.
This pilot does not compare selective reading with complete reading.

## Results

The pilot completed on 2026-11-13.

| Measure | No package | With package |
|---|---:|---:|
| Historical conclusion agreement | 6/6 | 6/6 |
| Primary criterion agreement | 6/6 | 6/6 |
| Unsupported-attribution control | 2/2 | 2/2 |
| False direct historical attribution | 0 | 0 |
| Resolvable cited references | No citations | 8/8 |

The model used documented analogies for the shipment-calendar and customs-timing cases.
It stated that the package did not document the freight-direction method or the cattle-protection instrument.
Reference resolution establishes text availability. It does not independently verify the new inference.

The CLI reported 38,906 input tokens across baseline runs and 99,430 across package runs.
These totals include harness context. They are not payload-only counts or billed-cost estimates.
The full inline package increased input volume. This result does not test selective-reading efficiency.

## Decision

No improvement in conclusion or criterion agreement was observed on this sample.
The baseline reached the test ceiling, so the design cannot distinguish person-specific judgment from generic inference.
The result does not invalidate package storage, navigation, or source traceability.
It also does not establish behavioral equivalence or a judgment benefit.

Do not change the skill's extraction rules based on this pilot alone.
Use open responses and less revealing case facts in the next evaluation.
Select cases that depend on documented personal criteria before comparing outputs.
A blinded human-review kit is prepared, but human evaluation remains NOT_RUN.
Its labels are randomized. Citations may reveal the condition, limiting blinding.

## Evidence boundary

A separate local verifier matched responses to runtime logs and checked frozen inputs and reference counts.
It passed one valid-data case and refused five invalid cases.
The invalid cases changed frozen input, erased answers, changed answers, claimed an empty human review, or altered a result count.
These are integrity checks, not tests of semantic fidelity.

Private source text, model responses, reviewer materials, and execution artifacts remain outside this repository.
No runtime dependency, installed skill behavior, or selective-reading capability changed.
