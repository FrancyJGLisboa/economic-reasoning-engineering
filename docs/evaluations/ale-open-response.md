# Ale Delara: reserved episodes with open responses

## Question

Does a faithful context package change agreement with a source analyst's conclusions and prioritized criteria on reserved episodes?
The pilot compares no personal context, raw eligible transcripts, and a structured portable package.
Raw context helps separate access to source material from the combined effect of extraction and package presentation.
It does not isolate folder layout from every other extraction choice.

## Frozen split

The supplied collection contains ten caption transcripts.
Two complete sources are reserved: the cattle discussion and the trade-balance discussion containing the soybean-production view.
The rare-earth export episode from 10:58 onward is also reserved.
Eight eligible sources remain, including the earlier part of the foreign-investment discussion.

The three reserved cases concern:

1. Fertilizer availability and acceptance of optimistic soybean-production estimates.
2. Near-term cattle support and later import-quota risks.
3. Primary-product exports, refining constraints, and the analyst's sovereignty position.

The third case tests application of a broader stated foreign-investment position to another resource question.
That broad position is present in eligible context. The specific rare-earth contract conditions remain withheld.
The cattle source has corrupted option terminology, so instrument selection is excluded from scoring.
Exact production estimates, price targets, and quota-completion dates are neither required nor supported by the supplied case facts.

The split, reference excerpts, and scoring rules are frozen before package extraction.
The case questions contain no candidate answers.
The investigator previously read the complete collection. This is not an investigator-blind or prospective time split.

## Context and execution

Names and provenance URLs are masked in evaluated context. Timestamps remain available.
The package contains eight source snapshots, fourteen episodes, fourteen opinions, and three documented method fragments.
It has 57 indexed records and passes structural validation and relocation checks.
All claims remain historical source statements. Dates, caption accuracy, forecasts, and legal assertions are not authenticated.

Each condition runs twice in a fresh session, ordered none, raw, package, package, raw, none.
The same open questions, output schema, and effort setting apply to every condition.
Raw text or the complete package is rendered inline. Native file navigation and selective reading are not measured.
Model recognition of the author or episode is recorded. Author recognition alone does not establish knowledge of a withheld episode.

## Assessment

The rubric scores decision direction, three source criteria, top-ranked priority, and calibrated precision separately.
A separate model session assesses anonymous responses. A second pass reverses their order.
This is model assessment, not human evaluation. Wording can reveal context condition despite anonymous labels.
Evidence anchors and record references receive separate deterministic checks.
Repeats do not create additional independent historical cases.

## Results

The package does not show a clear judgment advantage over raw source text in this sample.

| Context | Decision direction /12 | Source criteria /36 | Priority /12 | Calibration /12 |
|---|---:|---:|---:|---:|
| No personal context | 10–12 | 29–30 | 8–10 | 12 |
| Raw eligible transcripts | 12 | 30 | 8–10 | 12 |
| Structured package | 12 | 30 | 9–11 | 12 |

Ranges show the two assessor passes. They are not statistical confidence intervals.
The study has three historical cases, two repeats per condition, and eighteen case responses.
Both assessors use the same model family. These are not independent human judgments.

Raw text and the package receive identical criterion totals in both passes.
The package gains one priority point over raw text in each pass.
The assessor's own priority totals vary by two points between passes. The smaller condition difference does not establish a robust improvement.
One pass also penalizes generic baseline conclusions despite compatible qualitative direction.
This exposes uncertainty between direction, personal attribution, and priority scoring.

All conditions infer caution about optimistic production estimates and distinguish current cattle support from later demand risks.
Source context better recovers the analyst's stated distinction between foreign capital and sovereignty.
Neither source condition recovers the reserved episode's specific commercial-policy and technology-transfer conditions.
General local-employment criteria from eligible sources do not replace those missing conditions.

## Consumption and citation checks

Reported input tokens per session are 18,773 without personal context, 30,335 with raw text, and 71,746 with the complete package.
The complete package presentation uses 2.37 times the raw-text input.
These totals include runtime context and inline technical package files. They do not measure selective reading, native navigation, or monetary cost.

Fourteen of fifteen raw-text citations match the exact words at the stated timestamp.
One citation combines words across adjacent caption segments.
All fourteen package citations match source words and timestamps. All fourteen supplied record identifiers resolve.
Only eight cited records directly contain that timestamp in their own source references.
The remaining six cite real source passages associated with related records, but lack the direct record-to-passage link.
Text validity and complete citation lineage therefore receive separate results.

Execution checks pass for frozen inputs, complete responses, runtime correspondence, and the reserved-source split.
Negative checks reject changed questions, missing answers, and altered answer files.
These checks establish artifact integrity. They do not establish semantic fidelity or equivalent personal judgment.

## Limits and next test

The cattle question explicitly requests current support and later risks. This cues part of the reference direction and weakens that case.
The rare-earth case applies a broad investment position already present in eligible context.
These limitations were recorded after execution. No responses were discarded or rewritten to improve the result.

Raw-context sessions suspect the analyst's identity but do not report recognition of the specific reserved episodes.
One package session also suspects the identity despite a negative recognition flag.
Self-reports cannot establish the absence of prior knowledge.
The investigator previously read all sources, and the three cases allow substantial generic economic inference.

A stronger case should document two analysts choosing differently from the same facts.
It should test which criteria change their decisions and how they rank those criteria.
This pilot does not justify production rule changes or an identical-persona claim.
Human review remains pending. A randomized comparison kit and empty review form are prepared privately.
Private sources, reserved references, responses, and reviewer artifacts remain outside this repository.
